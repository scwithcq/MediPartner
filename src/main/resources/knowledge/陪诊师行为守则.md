# 陪诊师行为守则

## 一、基本职业素养

1. **守时**：提前 15 分钟到达约定地点；因交通等不可控因素可能迟到时，须第一时间通过平台虚拟号告知用户并致歉。
2. **着装与标识**：服务期间着装整洁得体，佩戴平台工牌，主动出示身份信息与订单详情供用户核对。
3. **沟通态度**：使用礼貌用语，耐心倾听，不催促、不打断用户；对老年用户放慢语速，必要时与家属同步信息。
4. **专业边界**：陪诊师不是医护人员，不得给出诊断结论、用药建议或治疗方案；涉及医疗判断的问题一律引导用户咨询医生。

## 二、隐私与合规红线

以下行为属**红线违规**，一经查实立即封号并保留追责权利：

1. 泄露、出售用户病历、检查报告、联系方式等个人隐私信息。
2. 私自添加用户微信绕开平台交易，或索取订单外费用、红包、礼品。
3. 伪造服务留痕、虚构服务过程、代签医疗文书。
4. 在院内从事号贩子行为（囤号、倒号、有偿代排专家号牟取差价）。
5. 对用户有任何形式的骚扰、歧视、辱骂行为。

## 三、服务过程规范

1. **服务开始前**：核对订单信息，与用户确认当日就诊安排与特殊需求（轮椅、空腹、儿童随行等）。
2. **服务进行中**：按节点上传留痕照片或文字记录（到院、挂号完成、候诊、就诊结束、取药取报告）；重要医嘱当场记录并复述确认。
3. **费用垫付**：挂号费、检查费、药费等院内费用原则上由用户自付；确需垫付的单笔不超过 500 元，须保留票据并当场在平台登记，事后凭票据结算。
4. **服务结束**：向用户当面交接报告、药品与随身物品，提醒复诊时间与注意事项，请用户在小程序确认完成。

## 四、冲突与投诉处理

与用户发生分歧时保持克制，先安抚再解释，不得争执；无法现场解决时报备平台客服介入。收到投诉后 24 小时内配合平台提供留痕与说明；恶意投诉可发起申诉，由平台仲裁。信用分低于 60 分将被暂停接单资格，完成整改培训并通过考核后恢复。
